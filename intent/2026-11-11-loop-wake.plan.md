# Plan: wake a run whose session died (fork-resume, capped, told)

Intent: `2026-11-11-loop-wake.md` (approved). Ticket: Plane APS-59. HARD: the main session (Opus 5.5) builds every
task; hard-reviewer (Fable 5.2) reviews.

## How it works

- `loop-stop.py` (Stop): records the session's `permission_mode` in the run as `mode` at every stop it judges.
- `loop-wake.py tick` (timer, every 10 min; one tick at a time through a lock): for each pointer in
  `~/.claude/1prompt-runs/` whose run is running and bound to that session, and only when the session is quiet 30 min
  (its transcript and every file under its folder unchanged, no live `busy` record in `~/.claude/sessions/`, no unit
  of any of the run's wakes running (a `systemctl` that cannot answer counts as running); a wake whose session never started is quiet from that wake and is forked again
  from its source):
  - past its deadline: close (`limit`), comment on the ticket;
  - the mode (run's `mode`, else the transcript's last `permissionMode`) asks or is unknown, or 1prompt's boundary
    settings are missing: not woken, the ticket told once;
  - 4 wakes used: close; before `next_wake`: not yet; less than $1 left of the day's $50: close;
  - else: a new session id, its pointer written first; the run gets `session` = new, `woken` += {from, to, at}, `wakes` + 1, `next_wake` =
    now + 30 min × 2^(wakes-1); the new pointer written, the old removed; a budget of min($20, left today) reserved in
    the ledger; `systemd-run --user --collect --no-block --unit 1prompt-wake-<run id>-<n> -p MemoryMax=8G -p
    RuntimeMaxSec=<to deadline>` runs `loop-wake.py child <run> <source> <new> <budget>`, which runs `claude -p
    --resume <source> --fork-session --session-id <new> --settings <boundary> --model <last model> --permission-mode
    <mode> --max-budget-usd <budget> --output-format json` in the transcript's first `cwd`, then replaces the
    reservation with `total_cost_usd` in the ledger on the reservation's day (no cost found: the reservation stays), adds it to the run and appends one line to
    `<git dir>/1prompt-wake.log`; a failed unit start gives the reservation back; the ticket is told (synchronously).
- `loop-wake.py install` / `uninstall`: the user timer and service, only from the installed copy under
  `~/.claude/hooks/loop/`.
- `loop.py resume`: also resets the wakes and binds the run to the resuming session.
- `install.py`: copies `loop-wake.py` beside `loop-stop.py`.
